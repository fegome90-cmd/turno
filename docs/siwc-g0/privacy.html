Privacidad y datos.

Borrador para revisión, no política vigente. Este texto acompaña una página de presentación y una demo sintética. No debe publicarse como política definitiva ni utilizarse para captar usuarios hasta identificar al responsable legal, el canal de contacto, el proveedor de alojamiento y los tratamientos reales del servicio.

1. Qué es Turno en esta etapa

Turno es un prototipo de organización personal de tareas, horarios y notas. El frontend React v6 se desarrolla con contenido de demostración en memoria de sesión. Todavía no dispone de una plataforma compartida de cuentas, un backend productivo, almacenamiento persistente remoto ni una integración habilitada con ChatGPT.

Por ello, no solicitamos nombres, RUT, historias clínicas ni información identificable de pacientes para participar en las pruebas del prototipo. No ingreses datos personales ni clínicos reales.

2. Qué hace esta página de presentación

Esta página está compuesta por archivos HTML, CSS y una imagen estática. No incluye formularios, registro de usuarios, scripts de analítica, cookies propias de seguimiento ni llamadas a modelos de IA. No pretende registrar actividad de quienes la visiten.

El proveedor donde se publique el sitio puede tratar datos técnicos necesarios para entregar el contenido —por ejemplo, dirección IP, fecha, agente de usuario y registros de acceso— de acuerdo con sus propias condiciones. El proveedor real de hosting y sus políticas deberán declararse antes de publicar la página como sitio oficial.

3. Qué hace la demo

La demo React v6 usa datos sintéticos y estados locales de interfaz para probar listas, tareas y revisión humana. Los cambios no se almacenan en una base de datos de producción ni sobreviven a la recarga conforme a su contrato actual. Esto no constituye una garantía de seguridad para introducir datos reales: el prototipo no ha pasado las validaciones necesarias para operar como un servicio clínico.

4. Qué se contempla para el futuro

El diseño futuro considera que una persona pueda vincular voluntariamente su cuenta individual de ChatGPT cuando OpenAI autorice la integración correspondiente, y que el análisis ambiental tenga un consentimiento separado. Esta función no está disponible actualmente. No recibimos ni guardamos tokens de ChatGPT de usuarios y no realizamos inferencia con sus suscripciones en este prototipo.

Antes de habilitar cuentas, colaboración, analítica o IA se publicará una versión revisada de esta política que identifique categorías de datos, finalidades, bases legales, encargados/proveedores, transferencias, plazos de conservación, medidas de seguridad, derechos de las personas y medios para ejercerlos.

5. Límites de uso

Turno no reemplaza registros institucionales ni está diseñado para almacenar datos de salud de pacientes, realizar diagnósticos, definir tratamientos o automatizar decisiones clínicas. El piloto de integración permite exclusivamente datos sintéticos; una operación con datos personales reales requiere una evaluación independiente de privacidad y seguridad.

6. Responsable y contacto

Responsable del producto y eventual tratamiento: pendiente de identificar y confirmar por quien mantiene el proyecto. Canal de contacto para solicitudes de privacidad y soporte: pendiente de habilitar y verificar antes de la publicación definitiva. No se sustituirán estos datos por cuentas personales, direcciones no verificadas o referencias a instituciones sanitarias ajenas.

7. Marco regulatorio y revisión

La política definitiva deberá revisarse de acuerdo con las normas chilenas aplicables. La Ley 21.719, que modifica el marco de protección de datos personales, tiene entrada en vigencia diferida al 1 de diciembre de 2026; si Turno se ofrece después de esa fecha, su implementación deberá considerar expresamente ese marco.

Fuentes oficiales para revisión: Ley 21.719, Biblioteca del Congreso Nacional y términos Sign in with ChatGPT de OpenAI. Este documento no constituye asesoría legal.
